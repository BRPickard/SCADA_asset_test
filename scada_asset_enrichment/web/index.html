Local MVP Launcher

SCADA Asset Enrichment MVP

This is a lightweight local HTML page so you can start and use the project quickly. The primary app experience still runs in Streamlit.

1) Install dependencies

From scada_asset_enrichment/:

pip install -r requirements.txt

2) Launch Streamlit app

streamlit run app.py

Once running, open: Open Streamlit (localhost:8501)

3) Key workflow

  1. Upload your workbook in Upload Inventory.
  2. Review normalized rows in Review Canonical Assets.
  3. Upload manuals in Upload Datasheets / Manuals.
  4. Run enrichment + schedule and export outputs.

Optional: host this HTML page

Run python run_local_web.py then open http://localhost:8080.
